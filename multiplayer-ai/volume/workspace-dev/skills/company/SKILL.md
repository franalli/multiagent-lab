# Company skill

This file holds workspace-wide knowledge: terminology, who-knows-what, and
conventions every agent run can rely on.

## Conventions
- Internal product codename differs from the public-facing name.
- Quarter naming: Q1 = Jan-Mar, ... Q4 = Oct-Dec.
- All-hands is Tuesdays 10:00 CET.

## Where to find things
- Engineering specs live in the team wiki.
- Customer-facing docs live in the support tool.
- Incident runbooks live in `integration/github/SKILL.md`.
